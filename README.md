# 机タイム 集中タイマー

丸い色がだんだん小さくなって、残りの時間が目で見て分かる集中タイマーです。「机タイム素材集」と連携します。

公開 URL: https://takahiroukai.github.io/tsukue-timer/

## 使い方

1. 上のタブで「さぎょう」「ちょっと休けい」「ゆっくり休けい」を選びます(初期値は 25 / 5 / 15 分)。
2. 「はじめる」を押すと、丸い色が上から時計回りに消えていきます。
3. 「ひと休み」で一時停止、「もどす」で最初に戻ります。
4. 終わると音で知らせます。作業が終わると、休憩に自動で切り替わります(4 回ごとに長い休憩)。
5. 「時間を変える」で分数と音の ON/OFF を変えられます。

完了した回数(今日・ぜんぶ)と設定は、このブラウザの中(localStorage)だけに保存されます。

## つくり

- 静的サイトのみ(HTML・CSS・素の JavaScript)。ビルド不要。公開物は `docs/`。
- 残り時間は「終了予定時刻との差」で計算するので、画面ロックやタブ切り替えでもずれません。
- 広告枠は `docs/index.html` の `#ad-slot`(いまは非表示・未実装)。
